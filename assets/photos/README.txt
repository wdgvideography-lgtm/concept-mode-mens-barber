AMC Transport Solutions — concept site photos
=============================================

Drop your photo files into this folder (assets/photos/) using the EXACT
filenames below. The site references these paths directly, so once a file
is present with the matching name it appears automatically.

Until a file is added, the site shows a tasteful navy/amber placeholder in
its place (and the animated SVG service scenes always work regardless), so
the page looks complete with or without photos.

Recommended format: .jpg (use .jpg extensions to match the references in
index.html). Landscape works best for most slots; the fleet cards are
portrait (3:4) and the gallery thumbnails are portrait (300x380).
